# Radxa triple-SBC enclosure exports

This directory contains the final fabrication and reference deliverables. For
the enclosure layout, assembly information, and complete BOM, see the
[project README](../README.md).

## `print-ready/`

Ten separate, flat, single-solid STL files plus matching STEP files. Import
each part separately into the slicer.

## `assembly-reference/`

Multi-body assembly files and the detailed bill of materials. These are for
fit-checking and reference only, not for one-piece slicing.

The detailed BOM is
[radxa_enclosure_detailed_bom.md](assembly-reference/radxa_enclosure_detailed_bom.md).

## `previews/`

Local render images of the print-ready parts.

The parametric CAD source remains in `models/*.step.py`.
