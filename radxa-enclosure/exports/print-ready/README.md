# Radxa enclosure — print-ready files

Each listed STL is a single closed printable part, already oriented with a
flat face on the build plate. Upload these files individually to the slicer.

Do **not** upload any file from `../assembly-reference/` to a slicer as one
print: those files are multi-part assembly views only.

2. `radxa_print_front_wall.stl`

4. `radxa_print_left_wall.stl`
5. `radxa_print_right_wall.stl`
6. `radxa_print_a5e_tray.stl`
7. `radxa_print_a7a_tray.stl`
8. `radxa_print_zero3e_tray.stl`
9. `radxa_print_fan_lid.stl`
10. `radxa_print_filter_retainer.stl`

Each STL has a matching standalone STEP file in this directory.
